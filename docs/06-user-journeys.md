# Opus Experience Studio User Journeys

## Journey: Create a Dashboard

User describes the desired experience using natural language.

Example:

Create a Security Master operational dashboard showing today's processing status, late files, failed files, new securities, and data quality issues.

The platform generates:

- KPI cards
- Charts
- Tables
- Filters
- Navigation
- Drill-down actions

## Journey: Security Overview

User searches for a security.

The platform provides:

- Security summary
- Asset-specific tabs
- Related parties
- Pricing information
- Overrides
- Audit history
- Data lineage

## Journey: Exception Management

Users can create operational workspaces for reviewing, correcting, approving, and tracking data issues.
