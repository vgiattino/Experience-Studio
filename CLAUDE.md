# Claude Code Instructions

## Project

You are working on Opus Experience Studio.

Opus Experience Studio is an AI-native enterprise experience platform that enables business users to create applications over governed enterprise data.

## Product Principles

- AI first
- Metadata driven
- Component based
- Enterprise governance
- Responsive by default
- Business user focused

## Direction

Do not recreate legacy Business Screens as a web clone. Design toward the future state.

The goal is to allow business analysts to create dashboards, search experiences, workflows, and applications using natural language and visual design.

## Architecture Expectations

Favor:

- reusable components
- JSON driven page definitions
- metadata abstraction
- scalable APIs
- testable designs
- maintainable Angular architecture

Keep documentation updated as architecture evolves.
